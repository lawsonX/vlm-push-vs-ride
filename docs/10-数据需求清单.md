> **这份文档列的东西，全部需要另一台能自由上网的设备下载，再由 lawson 手动搬到本设备。**

## 需求一（最优先）：旧设备的数据还能不能抢救？

原设备是 Windows + WSL，D 盘有 `vlm-active/frames/` 目录（全部帧图片），E 盘有 `vlm-data/`（原始视频和抓取清单）。

**如果旧设备还能开机（哪怕 GPU 坏了也不影响读硬盘），请整体拷贝这两个目录：**

1. `vlm-active/frames/` 整个目录（约 5GB）——这是全部已标注图片，拷过来就什么都不用重建了
2. `vlm-data/raw/` 下所有 `*_manifest.jsonl`（sogou_manifest、news_manifest、web_manifest 等）——记录了每张抓取图片的原始网址

**只要第 1 项能拷过来，需求二、三就都不用做了。**

如果只能拷一部分，优先级是：
1. `frames/trafficqa/` 里所有 `sg_*.jpg`、`j_*.jpg`、`c_*.jpg`、`y_*.jpg`、`news_*.jpg`（共约 250 张，这些是搜狗/网页抓的，本设备无法重建）
2. `frames/` 里所有 `BV*.jpg`（23 张）
3. 其他 b_ 帧（本设备能重建，不拷也行）

## 需求二：B 站视频下载（11 个视频）

清单文件：`docs/data-requests/bili_videos.jsonl`，每行一个视频，格式：

```json
{"bv": "BV1ek4y157nS", "frames_needed": [30077], "frame_ids": ["BV1ek4y157nS.f30077_f001"], "count": 1}
```

**要下载的视频（BV 号）：**

```
BV1494y1S7S6
BV14Qa76VEkd
BV1LR4y1j7tA
BV1Lc411N7u9
BV1Nr4y1k7A8      ← 注意：清单里写的是 BV1Nr4y1k7A8_p1，只要第 1 个分 P
BV1QM4y177FP
BV1Y44y1i7nH
BV1dUvzBdEqa
BV1ek4y157nS
BV1sw411A7up
BV1yB4y1M7VC
```

下载要求：
- 工具：yt-dlp（原项目用的版本），画质 480p 就够（`--format "bv*[height<=480]+ba/b[height<=480]/worst"`）
- **需要 B 站登录 cookie**（netscape 格式，原项目用浏览器导出的 cookie 文件）。yt-dlp 参数 `--cookies <cookie文件路径>`
- 输出命名：`%(id)s.%(ext)s`（例如 `BV1ek4y157nS.mp4`）
- `BV1Nr4y1k7A8` 只要第一个分 P（加 `--no-playlist`，或 playlist-items 1）

**下载后请放到一个目录里（比如 `bili_videos/`），lawson 整体搬到新设备的 `/home/lawson/vlm-data/raw/bili_videos/`。**

说明：`frames_needed` 里的数字（如 30077）是抽帧时的帧号提示，不用管，只要视频文件完整，我这边自己抽帧。

## 需求三：抓取图片的原始网址清单

sg_（199 张）、j_/c_/y_/news_（51 张）这些图是当初用脚本从搜狗图片搜索和新闻网页抓的，抓取时往 manifest 文件里记了每张图的原始网址。这些 manifest 文件**不在 git 仓库里**，只存在旧设备上，位置大约在旧设备的：

- `vlm-active/frames/web_sogou/sogou_manifest.jsonl`（sg_ 开头帧）
- `vlm-active/frames/` 下其他抓取目录的 `news_manifest.jsonl`、`web_manifest.jsonl`（j_/c_/y_/news_ 开头帧）

**请把这些 manifest 文件（所有叫 `*_manifest.jsonl` 的都行）全部找到，原样拷贝回来。** 拿到原始网址后，新设备可以逐个试着重新下载（部分网址可能已失效，能救一张是一张）。

如果连 manifest 都找不到，这 250 张图里已标注的约 205 张就永久损失了（其中含测试集 35 张），最后手段是重新抓取补测试集——但那需要重新标注，成本很高，请尽量找 manifest。
