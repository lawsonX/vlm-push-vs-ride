# 实验小结：A7 v0.6 数据重训（2026-10-18）

> 数据侧 v0.6 落地后的主实验：同 A1 配方（LoRA rank 32、lr 2e-4、有效批次 32、3 epoch），
> 训练集 v0.6（764 条 / 133 图，3 帧缺图已剔），测试集 v0.6 新口径（234 条 / 43 图，含 chain/guide）。
> 评测统一 256 token 口径（64 token 会截断长证据答案，chain 问法下是假象）。

## 1. 结果总表（v6 冻结测试集 234 条，同一判分器）

| 问法 | 基座 3B | A1（v0.4 数据训） | **A7（v0.6 数据训）** |
|---|---|---|---|
| overall | 86% | **95%** | 89% |
| direct | 100% | **100%** | 91%（4 错，其中 2 错是答案啰嗦致解析翻转） |
| chain | 90% | **100%** | 77% |
| guide | 39% | **100%** | 100% |
| caption | 93%（表态28） | 91%（表态43） | **100%（表态 43/43 且全对）** |
| probe_seat | 95% | **95%** | 79% |
| probe_feet | 90% | 86% | 88% |

## 2. 三个结论

**① v0.6 测试集是评测层面的大改进**：补了 chain/guide 问法、剔了 5 张误标测试图，第一次拿到 RQ4 的直接证据——基座 guide 只有 39%（先描述再结论会把它带跑），A1 训练后 100%。「固化证据习惯」这条路被证实可以学会。

**② 但 v0.6 训练集按原配方是负收益（89 < 95），根因是探针全覆盖+强行确定性标签。**
- v0.6 把探针覆盖率从 88 张提到 136/136（人工标注层），但 train 里「看不清」实际只有 1 条（probe_feet），probe_seat 是 0 条——**模糊的图全被标了确定的 有/没有**。
- 在真看不清的图上强行练一词答案，梯度互相冲突，模型直接把问答风格学混了：A7 的 probe_seat 43/43 条回答超 10 字（A1 是 0/43），direct 也有 31/43 条变啰嗦。啰嗦答案里两种词都出现，解析按「最后出现」判还会翻转标签。
- 这不是配方问题，是数据构造问题：v0.4 的做法（云端验证不过就不出该图探针）反而避免了冲突。

**③ A7 有两个真实收益**：caption 100%（43/43 全表态且全对，历史最好）；vd_9999998_00368 那帧空答案拒答被修好（现在能答且答对）。

## 3. 给数据侧的递话（重要）

- **「看不清」标注标准需要回潮**：人工标注层把 273 张探针几乎全标成确定性答案（seat 0 条、feet 1 条看不清）。从训练角度，**真看不清的图应该标「看不清」或不出探针样本**，强行标确定性答案会毒害训练（本实验实测）。lawson 标注时如果「努力看出了答案」，那些恰好是最该标看不清的。
- 3 帧图片缺失（train 16 条样本已剔）：bili3__BV11M4y1V7EQ.f100026.f000075__i0、bili3__BV1hKa96DEjZ.f30066.f000030__i0、items_bili3__BV1H2YMzfEC5.f30077.f000210__i0，请补图或从 train.jsonl 移除。
- test_ids.txt 还是 48 张的旧名单（含 5 张已剔除图），请更新为 43 张。
- 建议 v0.7：探针层按「确定性/看不清」重标（或只保留高置信确定性），测试集维持 v0.6 口径不动。

## 4. 当前最优与后续

- **当前最优仍是 A1（v0.4 数据）**：v6 测试集 95%。v6 数据的价值目前体现在评测集；训练集待数据侧修正探针标签后重训（预计可上 97%+，因为 caption/guide 都满分后只剩 probe_seat 的 2 错和 direct 0 错空间）。
- 复跑命令：`python scripts/train_sft_v2.py --model models/Qwen2.5-VL-3B-Instruct --data data/sft_v6_abs/train.jsonl --out ckpt/a7_v6 --epochs 3`；评测注意 `--max-new 256`。
