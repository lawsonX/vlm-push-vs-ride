## 数据生产线（全部脚本在 GitHub repo scripts/ 目录）
1. B 站采集：`filter_bvs*.py` 过滤 → `dl_bili*.sh` 下载（yt-dlp + cookie）→ `link_bili*.sh` 软链接
2. `extract_av.py` PyAV 抽帧（1fps、ahash 去重、模糊过滤）
3. `pair_items.py` YOLO 人车配对裁剪（item 级，1人1车）
4. `vlm_qc_cloud.py` 云端六问质检（qwen3-vl-plus，flash 已被阿里下线）
   - 六问：画面类型/有无两轮车/人车关系/清晰度/拍摄视角/人物朝向
   - 注意 q2 答「是」也算 yes（曾因此丢 492 条）
5. `merge_pool_wsl.py` 合池（--sources 筛选；只留固定监控视角+非背面+清晰）
6. `build_label_pool.py` 生成标注池

## 关键经验教训（给新设备 agent）
1. lawson 要的风格：**固定监控机位、人物正面或侧面、单人单车 item 级**。背面跟拍、第一人称、采访、摆拍一律不要。
2. B 站 scraping 边际效益递减：自然场景词→vlog/新闻；监控词→多为新闻解说素材。真固定监控画面在 B 站是稀缺品。
3. **SDD（Stanford Drone Dataset）是下一个数量级来源**：8 场景俯视、自行车轨迹占 20-50%。官方服务器已死，OpenDataLab 有 66GB 镜像（dataset id 88）。lawson 已在 opendatalab.com 登录。下载流：resolveDir → 轮询 progress → downloadCheck 拿 CDN 签名链接。
4. MOT17（已下载到 E 盘 raw/MOT17.zip，5.9GB）固定机位街景，自行车少但风格极正，已挖 38 张入 new_pool3。
5. 本机 GPU 半残（驱动崩过），本地 VLM 推理不可行，全部走 dashscope 云端 API。
6. wsl.exe 会吃掉命令行里的 $ 变量——带变量的逻辑必须写成脚本文件用 base64 部署。
