## 1. v0.7 实验结果（同测试集公平对照）

| 数据 | 种子 | overall（v0.7 测试集） |
|---|---|---|
| v0.4（现行冠军数据） | 42 / 7 / 1234 | **95% / 93% / 89%，均值 92.3%** |
| v0.7（lawson 修正后） | 42 / 7 / 99 | 87.2% ± 1.5（A8 管线） |

**裁决：维持 v0.4 冠军（`ckpt/a1_baseline/final`）为交付模型。** 按预先登记的标准（v0.7 均值 > 92.3% 才更换），v0.7 未达标。且冠军在 v0.7 修正后测试集上仍拿 95%——**同一模型、两套测试集（v6 与 v0.7）都是 95%**，这个双口径一致性是冠军稳健性的最强证据。

## 2. 为什么修正后的数据反而训不出更好的模型

lawson 的盲标是**对的**（152/170 确认原金标，改动全部合理），但修正集中在跨坐/电动车搁脚板帧（feet 踏板→地上），这批「正确的少数派」样本在 130 张图的规模下与主导的「踏板」模式梯度冲突——和 A7 同款机制（docs/24）。这不是标签的错，是**数据规模撑不起这个定义灰区的学习**：要教会模型「站立骑电动车=坐座+地上（跨坐）vs 骑行=坐座+踏板」，需要同类场景几十张而不是几张。probe_feet 69.8%±14.3 的崩法与 A7 如出一辙。

**结论：v0.7 的价值是数据与规范资产（定义 A、纠错清单、审计闭环），不是模型增益。剩余误差是数据规模问题，不再是标签质量问题。**

## 4. 给报告的收尾建议（RQ 视角）

1. **RQ2/RQ3 主线成立**：几百条人工金标 + 正确配方 = 把基座从 86% 修到 95%（均值口径 +6），幻觉（caption 把推行说成骑行）基本消除。
2. **最有意思的科学发现**：① 训练方差 ±4 分使一切单跑结论须打折；② Qwen3.5-2B 的 seat 系统性偏差（连 99% 基座也犯方向性错误）；③ 标签修正不一定提升模型——灰区定义需要数据规模支撑；④ 原生/外挂之争让位于「指令服从风格」解释。
3. **后续若重启**：跨坐/电动车场景定向采集 50+ 张真实新图，是当前已知唯一能把 feet 灰区学对的途径。
