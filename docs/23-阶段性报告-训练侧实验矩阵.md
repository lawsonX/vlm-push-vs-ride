## 2. 四个研究问题的最终答案（训练侧部分）

**RQ1（眼睛还是脑子）：脑子。** A6b 只训视觉把 direct 打到 75%（推行 12 张全误判骑行，幻觉方向复发）；基座 direct 本来 100%。区分线索在视觉编码器里已被提取，瓶颈在语言侧决策。

**RQ2（数据偏置）：成立，且是主因。** 基座 caption 表态率只有 15/48（不是不想答对，是答成了「骑行」惯性）；721 条配平金标把 caption 表态正确率修到 95%。

**RQ3（哪种微调手段）：强依赖基座，这是本阶段最重要的 caveat，且 4B 对照后结论再次细化。**
- 对 Qwen2.5-VL-3B：A1 配方有效（+4 点，caption 翻倍），且数据设计有讲究——混合问法必需（A2）、增强图有害（A3）、视觉别碰（A6）。
- 对 Qwen3.5-2B：基座 99%，任何微调都负收益（A4/A4b 掉到 90/88）。**不是配方问题，是基座 already 过了需要微调的那个点。**
- 对 Qwen3.5-4B（补做的规模对齐）：基座只有 75%——但主要不是视觉不行（caption 表态内 95%），而是**推理型风格不服从一词指令、结论经常被 token 预算截断**；A1 配方微调把格式修好（+6 点到 81%，48 张测试图全部表态），direct 71→85%，但仍追不上 2B 基座。
- **修正后的总规律**：对这个「一词答」型任务，**基座的指令服从风格比规模、比原生/外挂架构都更决定表现**。SFT 的价值 ≈ 把基座拉到任务格式 + 金标对齐：基座越偏（4B 话多）收益越大但有上限；基座已顺从且强（2B）时 SFT 净负。「原生多模态解决幻觉」不是家族规律（同族 2B 行 4B 不行）。最优解仍是 A1（3B 外挂 + 语言 LoRA，93%）。

**RQ4（不看证据直接答的习惯）：A1 部分实现。** caption 表态率 27%→81%、表态后 95% 正确；probe_feet 86%。但 probe_seat 有 4 帧难例空答案（看不清时拒答），chain/guide 的测试集问法缺失导致这条路径只能间接观测。

## 3. 给 lawson 的决策点

1. **报告主线建议**：训练侧最强结论是「基座的指令服从风格比规模/架构更决定表现 + 小数据 SFT 的有效性窗口」。这比「我们修好了模型」更诚实也更有价值——它解释了为什么 lawson 在 qwen3.6/3.8 云端观察到现象、而新一代开源小模型上表现分化（2B 顺从型已强、4B 推理型话多）。
2. **可选后续**（按性价比排序）：
   - Qwen3.5-4B 规模对齐（消除 A4 的 2B/3B 混杂变量）——约 1 小时机时；
   - 等数据侧补测试集 chain/guide 问法后重测 A1（回答 RQ4 的直接证据）；
   - probe_seat 的「看不清」第三类标签实验（需数据侧改标注体系）。
3. **RL（A5）建议不投**：信号稀疏（难例错误低熵稳定），重启条件已写在 docs/22。

## 4. 给数据侧的递话（汇总，详见 docs/19/21/22）

## 6. lawson 批注与决策（2026-10-17）

**代际纠正**：qwen3.6/3.8 才是新一代（重点上 RL 做 agentic 推理），qwen3.5 是上一代（传统 instruct 式后训练，未大规模上 RL）。

**lawson 的因果假设**（与本文证据相容，建议并入报告主线）：3.6/3.8 的幻觉源于 RL 推理后训练塑造的"必须给出结论"的回答偏好——即"病在脑子"的机制层解释；3.5 代无此训练故无此偏好（2B 基座 99%）。旁证：本项目 A5 实测 RL 在错例上"低熵稳定"（错得理直气壮不改口），RL 是偏置的放大镜，数据偏则造幻觉。

**决策**：
1. 报告主线采用训练侧建议（基座听话程度>SFT 有效性窗口），并加入上述 RL 因果假设。✅
2. 三个可选后续全做：①4B 规模对齐归训练侧；②测试集补 chain/guide（数据侧 v0.5 已完成，test.jsonl 161→231 条，含 chain/guide 各 35）；③"看不清"第三类探针答案实验——lawson 批准改标注体系，数据侧准备 273 张待标图（probe_label_todo.txt）+ 探针标注模式 UI。
3. RL（A5）维持不投。✅

**v0.6 数据已就绪（2026-10-17 深夜，数据侧）**：`data/sft_v6/`（GitHub 直接拉，免搬运）。要点：①探针答案有 lawson 人工标注层，"看不清"是合法第三答案（训练 136/136 全覆盖）；②39 张纠错图已剔，**测试集口径 48→43**（含 5 张原测试图被证误标），重测时评测脚本需用新 test.jsonl（234 条）；③跨坐 43 张在描述题里明示；④训练侧建议的"看不清"实验（A7）现在有数据了，可设计对照：v0.6 重训 A1 看难例拒答行为是否改善。
