# 进度日志 03：两个 CPU 侧归因实验出结果了（M4a、M4b）

日期：2026-09-30

## 实验 1：CLIP 零样本对照（眼睛 vs 脑子的分水岭）

对标注池 322 张图，CLIP（纯视觉模型，没有语言推理）对 3 组「推行 vs 骑行」英文描述打分，整帧和「人+车裁剪区」各算一遍。

**结果：**

| 视图 | 判「推行」 | 判「骑行」 |
|---|---|---|
| 整帧 | 63 | 259 |
| 裁剪区 | 36 | 286 |

但看分差：322 张里只有 **13 张明显偏向骑行**（平均分差 >2），**0 张明显偏向推行**，其余 309 张都是模糊地带。

**怎么解读（重要，别误读）：**

CLIP 偏向骑行**不能**证明「画面本身就是骑行」。CLIP 也是用网络图文对训练的，它可能带着和 VLM 一样的数据偏置（H1 对 CLIP 同样成立）。这个实验的真正结论要等你标完答案算「准确率」才能下：
- 如果 CLIP 准确率明显高于 VLM → 问题在语言侧
- 如果 CLIP 也大面积错 → 视觉线索提取确实困难（H2 加强）
- 目前唯一能说：区分推行/骑行的视觉信号对 CLIP 来说**很弱**（96% 的图分差在模糊区间）

## 实验 2：纯文本先验测试（H1 的语言先验部分）

不给图，只问「监控画面里一个人和一辆电瓶车在一起，更可能推行还是骑行？」每个模型采样 10 次。

**结果：**

| 模型 | 问题措辞 | 10 次采样 |
|---|---|---|
| qwen3-vl-flash | 电瓶车 + 监控画面 | 推行 10/10 |
| qwen3-vl-flash | 自行车 + 照片常识 | 推行 10/10 |
| qwen-vl-plus | 电瓶车 + 监控画面 | 推行 10/10 |
| qwen-vl-plus | 自行车 + 照片常识 | 骑行 10/10 |

**怎么解读：** 模型的先验**不是**一律偏向骑行，而是随措辞变：电瓶车+监控 → 都答推行；自行车+照片 → plus 答骑行、flash 答推行。两个模型的先验还互相矛盾。

这给 H1 提了个醒：「闭眼猜骑行」的故事可能没那么简单。如果文字先验在电瓶车场景是「推行」，而一看图就答「骑行」，那说明**是视觉信息把它推向了骑行**——这反而把嫌疑更多指向 H2（视觉线索被错误解读）或 H3（视觉到答案的映射被后训练带偏）。最终判定还是要靠：标注真值 + 各模型准确率对比。
