## 3. 四个研究问题的最终答案（训练侧）

- **RQ1 眼睛还是脑子**：脑子。只训视觉 direct 跌到 75% 且幻觉方向复发（A6，方向性结论不受方差威胁）。
- **RQ2 数据偏置**：成立且是主因。基座 caption 表态率 15/48，A1 训练后 39/48 且表态正确率 95%。
- **RQ3 微调手段**：强依赖基座 + 强依赖训练稳定性。Qwen2.5-VL-3B 有效（+6 分均值），Qwen3.5-2B 不需要（99% 基座，微调反伤），Qwen3.5-4B 居中（话多风格被 SFT 修好 +6）。同一配方在自己身上摆动 ±4 分。
- **RQ4 固化证据习惯**：可学会。基座 guide 仅 39%，训练后 100%（chain 同）；这是 v6 测试集新增问法给出的直接证据。

## 4. 模型行为发现（超出原问题的收获）

1. **Qwen3.5-2B 的 seat 探针系统性偏差**：对清晰的坐姿骑手高置信说「没有」（目检 4 例）。连 99% 强基座在探针级问题上也有方向性错误——本项目现象的又一个实例。
2. **Qwen3.5-4B 是推理型风格**：不服从一词指令，64 token 内结论被截断（评测假象），256 token 才是公平口径；SFT 可修格式。
3. **风格漂移**：小数据 LoRA 的啰嗦化不稳定，约半数训练会出现；交付需多种子挑选或降 lr（测试中）。
