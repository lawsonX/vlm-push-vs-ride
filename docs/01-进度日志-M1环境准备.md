## M2 数据下载（进行中）

- 网络方案定了：走 HuggingFace 国内镜像 hf-mirror.com。Windows 侧访问正常；WSL 里 curl 也能用，但 python 的 httpx 库会偶发连不上，所以不用官方下载工具，改用 curl 批量下。
- 踩了三个坑，都解决了：
  1. 从 Git Bash 往 WSL 传带 `$变量` 或中文 `&` 的命令会被吃掉 → 改走 base64 管道写脚本文件
  2. hf-mirror 下载地址会 302 跳转，curl 不加 `-L` 会把跳转提示页存成文件 → 脚本里加了 `-L` 和文件头校验（存成网页就删了重下）
  3. 每次 Bash 调用的 /tmp 不互通 → 中间文件统一放 E 盘 `_meta` 目录
- 已搭好总下载器 `~/master_download.sh`，在 WSL 后台持续跑，按顺序下三个数据集：
  1. TrafficQA（4111 段交通视频）——已下约一半（2.5GB）
  2. BDD100K 图片镜像（2 万张街景，带骑行者场景）
  3. Cityscapes 镜像（parquet 格式，约 2.5 万张街景）
- 进度随时看：`E:\vlm-data\raw\_meta\download_status.txt`
