> 日期：2026-10-15（v2 修订：按 lawson 复审意见修正结论与数字）
> 目的（lawson 拍板）：先把生成图调到理想状态，再测 VLM 表现、预估收益，最后决定是否正式进数据工程工作流。
> 产物位置：`E:\vlm-data\synth\`（iter1/2 为调参过程，iter3 为正式批次；图片不入 git）

## 0. lawson 的两条数据政策（2026-10-15 拍板，全项目生效）

1. **「跨坐」不算推行**：人跨坐/站在车上、双脚接地而非踩踏板、车基本静止——这种状态不属于推行，也不算标准骑行。合成图 QC 中这类一律剔除（记入 `qc_rejected.jsonl`，不进训练集）。将来如果要单独教模型识别这个状态，再单独立类。
2. **人工标为「不确定/无效」的图一律舍弃，永不进训练**。lawson 标注时的筛选标准就是"这张图对训练/测试有没有意义"，被打成不确定/无效的即脏数据。原训练方案里"invalid 当负样本"的设计作废（见 13 号文第 6 节 A3 已改）。

## 1. 结论（先看这个）

**合成图路线降级为"有条件的辅助手段"，暂不量产**，理由：

1. **清洁的合成推行图没能骗过云端强模型**：修正标签后（剔除跨坐类），云端 qwen3-vl-plus 对 23 张无歧义合成图 **100% 答对**（原图和监控化版都是）。之前观察到的"幻觉复现"全部来自跨坐模糊姿势——而那类图按政策要剔除。
2. 合成图对开源小模型（真正要微调的对象， hallucinate 率近 100%）有没有用，本实验测不了，要等 A1 训练后评估。花钱量产之前，不如先把免费的真实数据路线（难例挖掘、图像编辑增强）走完。
3. 生成器产量打折：推行候选里真正清洁的推行只有 **7/16（44%）**，其余是跨坐（4）和画成了骑行（5）。骑行类倒是 16/16 全对，但对训练是"简单题"，价值低。

**保留的价值**：合成线随时可重启（脚本、提示词公式、踩坑记录都在），等 A1 实验证明"小模型在合成图上确实犯错"后再放量，是最省的顺序。

## 2. 过程与关键发现

### 2.1 CLI 踩坑记录（复用前必读）

用百炼 `bl image generate` 实测踩出的坑，都验证过：

| 坑 | 现象 | 对策 |
|---|---|---|
| wan2.2-t2i-flash 提示词长度限制 | 长中文提示词直接 HTTP 400 | 它只吃短提示词；复杂提示词用 qwen-image-2.0 |
| `--prompt-extend false` 传给 qwen-image 同步模型 | 返回与提示词完全无关的"回退图"（女人脸、毛驴等，同批 4 张还一样） | qwen-image 系列不要传这个参数 |
| 提示词经 bash 函数/变量多层传递 | 同样触发无关回退图 | 用 Python subprocess 列表传参（scripts/gen_synth.py 已是这么做的） |
| 水印 | 默认右下角"AI 生成"水印 | `--watermark false` 可关（qwen-image 系列验证过） |
| 限速 | 文生图 QPM 1~2 次/分钟 | 请求间 sleep 5~8 秒；`--n 4` 一次出 4 张摊薄请求数 |

### 2.2 提示词公式（把活动正确率从 25% 拉到可用）

**活动描述放最前面，风格描述放后面**，再加负面提示词：

```
画面中央，一名{角色}{做什么：站立、双脚走路、推行…}。{监控风格描述}。{背景}。
负面：坐在车上,骑车的姿势,脚踩踏板,摆拍,艺术写真
```

- 第一轮（风格在前、无负面词）：推行正确率 25%（生成器爱画"骑行"——和 VLM 的幻觉方向一致，挺讽刺的）。
- 第三轮（活动在前 + 负面词 + 六种角色轮换）：画面"看起来像要的"比例大幅上升，但按 lawson 的严格标准复核后，真正清洁的推行只有 7/16，问题集中在：
  - **自行车推行极易画成坐着**（5/8 不合格）；
  - **电动车推行爱画成跨坐**（站在踏板上、屁股悬空）——4/8 是跨坐。这个姿势恰恰是真实世界里人和 VLM 都最容易纠结的姿势。

### 2.3 监控化后处理

脚本 `scripts/synth_cctv_style.py`：缩放到 1280×720 → 轻模糊 → 降饱和偏绿 → 加噪点 → 压对比 → 暗角 → JPEG 压缩（q=70）。

**效果：有监控感但仍一眼能看出是"处理过的好照片"，和真监控的差距还在。** 好消息是修正标签后监控化版没有再毁掉任何判断（无歧义图 100% 答对两版都对），坏消息是它也证明了监控化目前不改变模型行为，风格差距问题没真正解决。

## 3. VLM 测试结果（云端 qwen3-vl-plus，直接问法，修正标签后）

23 张无歧义图（7 推行 + 16 骑行 × 原图/监控化两版，共 46 次调用）：

| | 推行图答对率 | 骑行图答对率 |
|---|---|---|
| 原图 | 7/7 = 100% | 16/16 = 100% |
| 监控化 | 7/7 = 100% | 16/16 = 100% |

- **v1 报告（已被本版取代）里说"合成图复现幻觉 18~27%"，那个信号全部来自跨坐类模糊图**——剔除后云端强模型零错误。这提醒我们：在推行/骑行的边界姿势上，"正确答案"本身就依赖于明确的判据（双脚位置、车在不在动），数据标注必须按 lawson 的严格定义执行。
- 云端强模型测不出合成图对**开源小模型**的难度——这是本实验的盲区，只有 A1 训练实验能回答。

## 4. 收益预估（修正版）

- 对本项目当前阶段（SFT 冷启动教概念），合成图的替代优先级低于：真实难例挖掘（便宜、真实分布）、图像编辑增强（标签继承、零标注成本）。
- 合成线的重启条件：A1 训练后，开源小模型在"真图+合成图"上比"只真图"提升明显，或真实推行图怎么挖都不够（< 150 张）。
- 若重启：主攻电动车清洁推行（提示词把"双脚在地上交替走路、身体完全在车的一侧"写到极致），自行车推行单独调；量产目标 100 张量级，预算 60~100 元。
