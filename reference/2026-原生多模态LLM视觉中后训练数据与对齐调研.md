# 2026 原生多模态 LLM：视觉中后训练数据与对齐

**资料截止：2026-09-25**

## 问题重构

2026 年发布的原生多模态大模型，在中训和后训阶段具体使用了哪些视觉数据？按图像 QA、视频 QA，以及 caption、OCR、grounding、pointing、tracking 等非严格 QA 任务归类；再比较各家如何通过 SFT、偏好优化和强化学习，让模型依据视觉证据作答。调研中区分已确认的训练数据、只披露类别的数据，以及未公开信息，不把评测集误当训练集。

## 调研结论

- 公开到“数据集名称 + 训练阶段”的模型不多。**Molmo2** 的训练代码最便于逐项核验；**Nemotron 3 Nano Omni** 公开了部分 SFT、偏好和 RL 数据及流程。
- **Phi-4-Reasoning-Vision、ERNIE 5.0、InternVL-U** 披露了数据类型和训练方法，但没有完整公布具体视觉数据集清单。
- **Qwen3.5、Gemini、GPT、Claude** 等模型的公开资料不足以还原其视觉中训/后训数据集。不能根据能力或评测成绩反推训练数据。
- 视觉对齐已不只是“用 VQA 做 SFT”：较完整的方案会组合描述、OCR、空间定位、视频时序、偏好比较和可验证奖励，并通过阶段编排控制不同模态之间的能力干扰。

### Molmo2 的视频 QA 细目

官方 SFT 代码将视频学术数据单独列为训练混合，包含 `TGIF`、`TVQA`、`Paxion`、`LLaVA-Video`、`PerceptionTest`、`NExT-QA`、`NewsVideoQA`、`How2QA`、`SUTD-TrafficQA`、`Social-IQ`、`SportsQA`、`CinePile`、`CLEVRER`、`FunQA`、`STAR`、`IntentQA`、`Moments-in-Time-QA`、`Kinetics-QA`、`Charades-STA`、`COIN`、`YouCook2`、`ActivityNet`、`Ego4D`、`EPIC-Kitchens`、`QVHighlights`、`Countix`、`CameraBench` 和 `MotionBench` 等。自建 VixMo 合成集合还含通用视频 QA 和字幕 QA。

其中 `video academic` 不是全都属于传统问答：部分数据是事件/动作理解、时间定位、字幕或叙事监督。Molmo2 还把 pointing、grounding、tracking 作为独立 SFT 任务；这些监督提供了 QA 之外的时空对齐信号。

## 视觉 LLM 后训练如何做对齐

1. **先对齐视觉表示和语言接口。** 使用图文/视频文本、caption、OCR 和交错序列，让视觉内容能进入生成式语言上下文。架构上可以是视觉编码器加投影层，也可以是早期融合 token 流。
2. **再做多任务 SFT。** 混合感知、文档、图表、推理、空间定位、视频时序、多图比较和 GUI 数据。简单识别任务应保留简短直接回答；复杂任务可训练结构化推理，避免所有样本都被拉成长 CoT。
3. **用偏好数据校正答案质量。** 对同一视觉输入比较多个候选，检查事实是否来自图像、时序是否正确、定位是否准确、是否幻觉，以及格式/拒答是否合适，再做 DPO/MPO 等偏好优化。
4. **在可判分任务上做 RL。** 数学、OCR 数值、计数、选择题、坐标定位、时间戳、工具调用等可以使用答案正确性、格式和定位奖励。开放式 caption 或解释需要更谨慎的视觉裁判/偏好奖励，避免奖励模型幻觉和 reward hacking。
5. **控制阶段间的能力漂移。** 分开安排文本、视觉和全模态 RL；用混合回放、模态采样配比、冻结部分输入表示、保留 caption/感知回归集等手段，防止文本优化削弱看图能力，或长推理挤占直接感知能力。

一个可复用的训练顺序是：

```text
多模态继续预训练
→ 多任务视觉 SFT（QA + caption/OCR + grounding/pointing + video）
→ 偏好优化（视觉证据、准确性、校准、安全）
→ 可验证视觉 RL
→ 视频/工具/agent 场景 RL
→ 多模态回归与安全评估
```

## 解释这些清单时的边界

- 上表中的数据集名称来自技术报告或官方训练代码披露；**评测列表不自动视为训练数据**。
- 有些公开代码暴露的是训练 mixture，但数据源可能有授权限制、内部版本或未开放预处理细节。数据名可核验，不代表原始数据均可下载。
- “合成 QA”“内部领域数据”“数百万条多模态样本”等类别级披露，不能据此推断其底层具体来自哪些 benchmark。
- 闭源模型未披露数据集时，结论应为“未知/未公开”，而不是用常见 VQA 数据集补全。
